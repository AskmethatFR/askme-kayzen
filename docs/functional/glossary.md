# Ubiquitous Language — Glossary

> Functional node (owner: pm). The words the domain speaks — code identifiers must match these terms. Features using them: [[feature-catalog]].

| Term | Meaning | Code anchor |
|---|---|---|
| **Habit** | An easy habit a user commits to; exists only once its request was accepted and handled. Identified by a `HabitId`. | `core/src/habit_management/domain/habit.rs` |
| **Habit Board** | The single entry point where habits are requested. Guards the habit rules AND its own invariants — at most 5 habits in parallel, no duplicate title — and remembers every accepted request. | `core/src/habit_management/domain/habit_board.rs` |
| **Request (a habit)** | Asking the board for a new habit. Validated synchronously; acceptance is recorded on the board and produces a `HabitRequested` fact. | `core/src/habit_management/use_cases/request_habit.rs` |
| **HabitRequested** | The fact that a valid habit request was accepted. Reliable by construction — carries already-validated values, never re-checked downstream. | `core/src/habit_management/domain/habit_board_event.rs` |
| **Title** | What the habit is, in the user's words — a simple title. 1 to 50 characters after trimming; case is preserved but ignored when comparing two titles. Self-validating value (`HabitTitle`). Formerly called "description". | `core/src/habit_management/domain/habit_title.rs` |
| **Duplicate** | Two habits with the same title, ignoring case and surrounding whitespace. Forbidden on the board; reported as duplicate even when the board is also full. | `core/src/habit_management/domain/habit_board.rs` |
| **Ancrée (anchored)** | *Future rule*: how a habit will eventually leave the board and free one of the 5 slots. Not implemented yet. | — |
| **Goal (*objectif*)** | A habit's soft **daily goal** in minutes — default 5, floor 1, **no upper ceiling**. A flexible aim, not a limit: doing less is fine, doing more is a bonus. Self-validating value (`Goal`). Replaces the old "initial duration ≤ 5" (superseded by `[[adr-0008-goal-based-dose-user-paced-progression]]`). | `core/src/habit_management/domain/goal.rs` |
| **Completion (*fait*)** | A day a habit was marked done. One per local date, toggleable the same day, kept forever, no timestamp. Lives inside the `Habit` aggregate. | `core/src/habit_management/domain/completion_history.rs` |
| **Completion history** | The set of a habit's completed days. One-completion-per-day is **structural** (an ordered set, never a runtime guard). | `core/src/habit_management/domain/completion_history.rs` |
| **Mark done (*toggle*)** | Toggling today's completion for a habit — fills the ink if empty, clears it if already done. A lifecycle transition kept internal (no event published). | `core/src/habit_management/use_cases/mark_done.rs` |
| **Goal floor** | One minute — the lowest a goal can go. A **business rule, not a display convenience**: below one minute there is no shorter habit, there is *no habit*, and deleting it is the only legitimate exit (deletion not built yet). Enforced twice: `Goal` cannot be constructed below it, and *alléger* cannot cross it. | `core/src/habit_management/domain/goal.rs` |
| **Grandir (*grow*)** | The user's gesture raising a habit's goal by one minute. Always available, at the user's own pace — the app never detects readiness and never suggests it. | `core/src/habit_management/use_cases/grow_goal.rs` |
| **Alléger (*lighten*)** | The user's gesture lowering a habit's goal by one minute, floored at one. *Alléger n'est pas reculer, c'est enlever ce qui freine* — never framed as a setback. At the floor it changes nothing, silently: no error, no message, no disabled button. | `core/src/habit_management/use_cases/lighten_goal.rs` |
| **Step (*marche*)** | One dated goal change — the day it happened and the goal it moved to. | `core/src/habit_management/domain/step_history.rs` |
| **Step history (*croissance en escalier*)** | The dated staircase of a habit's goal changes, seeded at creation. **Append-only**: both gestures add a step, none is ever removed, merged, or undone — two changes on the same day stay two steps. The current goal is always the last one, never stored apart. Since slice 3b it is **data, not a drawing**: it gives every practice bar its height and will feed "minutes gagnées", but no screen renders it. | `core/src/habit_management/domain/step_history.rs` |
| **Practice staircase (*escalier de pratique*)** | The detail's one drawing: a bar per calendar day over the **last seven days**, full when the day was practised and faint when it was not. Answers two questions at once — *am I keeping it up* (the run of bars) and *am I raising, easing or holding my effort* (their profile). Draws **practice, never intent**: adjusting the goal adds no bar. Derived on read, nothing stored. | `core/src/habit_management/queries/get_habit_detail.rs` |
| **Practice day (*jour de pratique*)** | One bar of the practice staircase: whether the habit was done that day, and the goal active on it — the last step dated on or before it. A day older than the habit falls back to the goal it started on. | `core/src/habit_management/queries/get_habit_detail.rs` |
| **État du cycle (*lifecycle state*)** | Where a habit stands in the user's day: **Active** or **En pause**. One state at a time, never a pair of flags — an impossible combination cannot be written down. *Ancrée* joins it in slice 6. | `core/src/habit_management/domain/lifecycle_state.rs` |
| **Mettre en pause (*pause*)** | Setting a habit aside, at any moment, without justifying it. It leaves the day's list and joins the paused zone; nothing is lost and nothing is counted against the user. The domain forbids nothing to a paused habit — it is the screen that stops offering, not the rule that starts refusing. | `core/src/habit_management/use_cases/pause_habit.rs` |
| **La reprendre (*resume*)** | Taking a paused habit back into the day, in one gesture, from its row in the paused zone or from its detail. Every day it had already lived is untouched — resuming is a return, not a restart. | `core/src/habit_management/use_cases/resume_habit.rs` |
| **Zone « En pause · aucune pression »** | Where paused habits wait, under the day's list. Shown only when something is actually at rest: a heading over an empty space would be a silent reproach. | `app/src/views/today.rs` |
| **Local date** | A calendar day in the user's timezone. Library-free by design — no `chrono` in the domain; an epoch-day integer internally. | `core/src/shared/local_date.rs` |
| **Clock** | Port giving the domain "today" as a `LocalDate`; the real `SystemClock` (the only place `chrono` is used) sits at the infra edge. | `core/src/shared/clock.rs` |
| **Outbox** | Where accepted facts wait to be handled. Published in the same transaction as the board's acceptance. | `core/src/habit_management/infrastructure/in_memory_outbox.rs` |
